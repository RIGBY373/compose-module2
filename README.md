# Модуль 2 – Основы Jetpack Compose

Практические задания по дисциплине «Проектирование и разработка мобильных приложений на языке Котлин».

Каждое задание лежит в своём пакете `task01` … `task10`, UI-тесты задания 9 находятся в `app/src/androidTest`.
Ресурсы: `app/src/main/res/values/strings.xml`, `app/src/main/res/drawable/circle.xml`.
